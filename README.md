## ✦ What is KEHATI?

**KEHATI Bento Learning Lab** turns biodiversity material into a visual, interactive learning space.

Instead of scrolling through one huge wall of text, concepts are organized into **Bento cards, visual summaries, flashcards, recall tools, and quizzes**.
